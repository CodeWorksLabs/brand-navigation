# Product scope

Brand Navigation is a focused theme component for site-global identity and
navigation on normal Discourse application pages.

## Included

- Optional brand header.
- Brand logo, dark-scheme logo, name, destination, and presentation.
- Ordered top-level links and one child submenu level.
- Internal and external destinations.
- Desktop, tablet, and mobile behavior.
- Mobile bar, compact menu, and hidden modes.
- Keyboard and assistive-technology semantics.
- Theme and color-scheme compatibility through Discourse color variables.
- Anonymous and authenticated audience rules.
- Structured, validated administration with empty, safe defaults.
- Explicit full-application and embed render boundaries.

## Excluded

- CMS behavior and general page building.
- Arbitrary deep navigation nesting.
- Authentication replacements.
- Changes to core Discourse embedding.
- DiscussionBridge compatibility logic.
- Hostname, CSS, or DOM-selector embed workarounds.
- Literal integration into Discourse core as an initial requirement.
